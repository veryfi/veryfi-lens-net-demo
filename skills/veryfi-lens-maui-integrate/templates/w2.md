# W-2

Cloud extraction of `w2` on the Full UI SDK this plugin links. Not a W-2 package. Engine `"api"`. `"mobile"` does not apply.

The pinned sample never sets `w2`. If detection fails, the model may be absent from the vendored xcframework or the `2.7.0.3` AAR. Say that is **Unconfirmed** and ask support. Do not add a flavor URL.

## Permissions

Camera usage string. Photo library usage because gallery and browse are on. Backup is off, so skip the photo-add string. Location is off.

`browseIsOn` does not show Browse while `moreMenuIsOn` is false. Use `ShowDocumentBrowser(page)` when Files is the entry point.


One type, so the picker stays off. Stitch stays off: a W-2 is not a long receipt.

## Present

`ShowCamera(page)` or `ShowGallery(page)` or `ShowDocumentBrowser(page)`. One of them.

`OnSuccess` package results use `status` `"done"`. Keep local files only if you set `autoDeleteLocalResourcesAfterProcessing` false; otherwise copy paths inside `OnUpdate`.

W-2 is not Any-Documents. Do not set `anyDocumentTemplate` here.

## Do not

- Set `"mobile"` or `"custom"`
- Turn on `fraudDetectionIsOn` or `documentFieldsToDetect` to "get the form fields." Those are paid, backend-gated, and field detection is not in this binary
- Copy scans into Photos. Backup stays false
