# W-9

Cloud extraction of `w9` on the same Full plugin binary as W-2. Not a separate package. Engine `"api"`.

The sample does not set `w9`. A missing model in the vendored binary is **Unconfirmed** until a scan or support confirms it. Do not switch artifacts from this skill.

## Permissions

Same as W-2: camera, and photo library because gallery is on. No photo-add string (backup is false). No location string.

## Settings

```csharp
var settings = new Dictionary<string, object>
{
    ["ignoreRemoteSettings"] = true,
    ["backupDocsToGallery"] = false,
    ["backupDocsToiCloud"] = false,
    ["moreSettingsMenuIsOn"] = false,
    ["moreMenuIsOn"] = false,
    ["autoCaptureOtherIsOn"] = false,
    ["showNoDocumentDetectedWarning"] = false,
    ["dictateIsOn"] = false,
    ["locationServicesIsOn"] = false,
    ["enableScreenshots"] = true,

    ["dataExtractionEngine"] = "api",
    ["documentTypes"] = new[] { "w9" },
    ["showDocumentTypes"] = false,
    ["autoCaptureIsOn"] = false,
    ["stitchIsOn"] = false,
    ["galleryIsOn"] = true,
    ["browseIsOn"] = true,
    ["autoRotateIsOn"] = true,
    ["cleanBorderIsOn"] = true,
    ["returnStitchedPDF"] = true
};
```

`browseIsOn` is the More-menu Files row and stays hidden while `moreMenuIsOn` is false. `ShowDocumentBrowser(page)` opens Files without that menu.

## Present

One call after configure: `ShowCamera`, `ShowGallery`, or `ShowDocumentBrowser`. Pass the page.

iOS completion false means do not present. Android completion true does not mean the credentials worked. Implement `OnError`.

## Do not

- Reuse the W-2 dictionary with the type string left as `w2`
- Set `anyDocumentType` or an Any-Documents template. W-9 here is document type `w9`
- Enable gallery backup. W-9 images should not be copied into Photos or iCloud unless the host asked
- Promise Lite, Headless, or Remote Models
